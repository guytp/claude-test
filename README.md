# CSharp Hello Learner

A simple C# console application designed as a teaching vehicle for complete beginners who want to learn programming fundamentals.

## Prerequisites

To work with CSharp Hello Learner, you need:

1. **.NET 8+ SDK** - Required to build and run the C# application.
2. **A text editor** - Any basic editor will work (Notepad, TextEdit, nano, or Visual Studio Code).
3. **A terminal or command prompt** - The built-in terminal on your operating system.

You do **not** need a full IDE like Visual Studio or Rider - a simple text editor and the command line are all you need for these exercises.

**[Install .NET 8 SDK](docs/dotnet-sdk-installation.md)** - Follow our step-by-step guide for Windows, macOS, and Linux.

## Quick Start

Once you have the .NET SDK installed, verify it works by opening a terminal and running:

```bash
dotnet --version
```

You should see a version number starting with `8.` (for example, `8.0.100`).
